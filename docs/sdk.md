# Using the SDK in another app

`@timegems/sdk` is a portable, self-contained API + hook layer. Any React app can install it — a future mobile (React Native) client would get full typed data access with zero backend-specific code.

```bash
pnpm add @timegems/sdk @tanstack/react-query
```

## Setup

```typescript
import { createApiClient } from '@timegems/sdk'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

createApiClient({
  baseUrl: 'https://api.yourapp.com',
  // Web uses httpOnly cookies automatically (credentials: 'include').
  // Native apps (no cookies) pass getToken to inject a Bearer header instead:
  // getToken: () => SecureStore.getItem('token'),
})

// Wrap your app in <QueryClientProvider client={queryClient}>
```

## Usage

```typescript
import { useActiveWorkSession, useStartWorkSession, useCurrentUser } from '@timegems/sdk'

function WorkScreen() {
  const { data, isLoading } = useActiveWorkSession()
  const startMutation = useStartWorkSession()
  // ...
}
```

All hooks are typed from the OpenAPI spec — `packages/sdk/src/generated/types.ts` is regenerated by `pnpm sdk:generate` and never hand-edited.

## Hook modules

| File | Covers |
|---|---|
| `useAuth.ts` | `useCurrentUser`, `useGoogleAuth`, `useLogout` |
| `useTenants.ts` | `useMyTenants`, `useCreateTenant`, `useSelectActiveTenant` |
| `useTeams.ts` | Teams + team membership CRUD |
| `useProjects.ts` | Project list/detail/create/update |
| `useWorkSessions.ts` | The core loop — active session, start/pause/resume/stop/update, history list |
| `useNotes.ts` | Notes on a work session |
| `useReports.ts` | `useTimeSummary` (Views — daily/monthly/yearly × individual/team) |
| `useAgentReports.ts` | The in-app agent report feed |
| `useAdmin.ts` | Site-admin tenant/user/agent-employee management |

## Query key convention

`['entity']` for global/self resources, `['entity', id]` for a resource by ID, `['entity', 'list', params]` for filtered lists. Mutations invalidate using the exact same key shape as the query they affect — mismatched keys fail silently with stale data, so when adding a hook, match this pattern rather than inventing a new one.
